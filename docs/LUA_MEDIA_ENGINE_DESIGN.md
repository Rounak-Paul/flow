# Superseded Lua media engine proposal

The consolidated implementation design is [Flow media engine: final architecture](DOCUMENT_COMPONENT_BEHAVIOR_DESIGN.md).

The earlier module-first proposal is superseded. Lua is a component behavior language within a complete entity/component media editor; readable project documents, editor actions, MCP and file edits share one validated model. The consolidated design includes time mapping, procedural ownership, simulation replay, media/render/export, implementation boundaries and acceptance requirements.

Implementation is in progress. The current owner map and outstanding work are recorded in `.context/media-engine-refactor.md`, `.context/lua-components.md` and `.context/prototypes.md`.
